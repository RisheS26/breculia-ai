# Breculia AI Website

Static marketing website for **Breculia AI** and its AI voice receptionist product, **Emma**, focused on contractors (HVAC, plumbing, roofing, and electrical).

## Project Structure

- `index.html` — main landing page
- `partners.html` — partner-facing page
- `terms.html` — terms of service
- `privacy.html` — privacy policy
- `refund.html` — refund policy
- `logo-favicon.png`, `rishe.jpg` — site assets
- `robots.txt`, `sitemap.xml`, `llms.txt`, `CNAME` — SEO and deployment/domain files

## Local Preview

Because this is a static HTML site, you can preview it by opening `index.html` directly in a browser, or by serving the folder with any static file server.
